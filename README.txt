EVERYDAY LEAN AU 2.0 — PHONE-FRIENDLY RECIPE APP

QUICK START:
1. For a quick preview, open Everyday_Lean_AU_2.html in a modern web browser. All 26 original recipes are bundled in the HTML file.
2. For installable PWA behaviour (Home Screen icon and offline app shell), upload the contents of this ZIP to an HTTPS static website (for example GitHub Pages, Netlify or Cloudflare Pages). Serve index.html at the website root or a subfolder, then in iPhone Safari use Share > Add to Home Screen.
3. Online recipe search uses TheMealDB and requires internet. Australian recipe links open Google searches restricted to their websites. If the search API has a network/CORS problem, use the Australian-site links.
4. The app uses this browser's local storage. Export your JSON backup under Settings regularly; storage is not automatically shared across browsers or devices.

AUSTRALIAN DETAILS:
Metric grams/mL; Australian cup = 250 mL, tablespoon = 20 mL, teaspoon = 5 mL; kJ + kcal; A$ optional user-entered grocery prices; Australian recipe sources.

NUTRITION:
The macro engine uses editable typical nutrient reference values, not brand-verified products or an official FSANZ nutrient database. Use Settings > Custom ingredient nutrition to enter energy in kJ, protein, carbs and fat per 100 g directly from Australian product labels. Originally supplied per-meal macro estimates remain visible as historical guide estimates. For imported recipes, unsupported units are flagged and excluded from estimates until mapped. Do not treat partial estimates as complete.

SOURCE / PRODUCTION:
TheMealDB free test key 1 is used as documented for development/demo. A production key may be required when releasing the app publicly; verify provider terms before widespread distribution. Imported recipes preserve the original instructions, ingredient texts and link attribution when provided by the source. No backend, accounts, price scraping or auto-sync are provided.
